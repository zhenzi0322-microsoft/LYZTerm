# LYZTerm

一款清爽易用的 **SSH 终端桌面应用**，为经常远程管理服务器的你准备。
多标签、分屏、会话收藏、文件传输、端口转发，一个窗口全搞定。

![平台](https://img.shields.io/badge/platform-Windows-lightgrey)
![版本](https://img.shields.io/badge/version-v0.2.1-blue)

## 下载安装

前往 [Releases](../../releases) 页面，下载 `LYZTerm_x.x.x_x64-setup.exe`，双击安装即可。

- 支持 Windows 10 / 11（64 位）
- 安装后可从系统托盘常驻，随时唤出
- 应用内置自动更新：发现新版本会提醒，一键升级

## 主要功能

### 会话管理
- 把常用的服务器连接保存为会话：名称、主机、端口、用户名、认证方式，一次配置长期复用
- 左侧列表按分组整理，支持搜索、新建、编辑、删除
- 双击即连，启动时自动恢复上次的标签现场
- 支持会话的导入 / 导出，换电脑也能一键迁移
- 所有连接信息只保存在你的电脑上，密码不以明文形式存储

## 配色方案

 [iTerm2主题预览](https://iterm2colorschemes.com/) 

> 目前主题已经支持`iTerm2`的主题集合。只需要将`.terminal`主题文件通过应用->终端->配色方案->导入配色文件即可。

### 终端体验
- 多标签并行，每路连接互不干扰
- 单屏 / 左右 / 上下 / 四宫格 / 六宫格分屏布局，同屏掌控多台服务器
- 可把会话拆成独立窗口，多显示器办公更顺手
- 右键菜单：复制、粘贴、全选、搜索、全屏、清屏、SFTP 文件管理
- 快捷键支持自定义改绑
- 深浅色主题，字号随心缩放
- 响铃提醒：声音 / 任务栏闪烁两种模式，长任务完成不漏看

### 远程文件（SFTP）
- 连接服务器后可直接打开文件管理面板，浏览、上传、下载、删除远程文件
- 自动定位到终端当前所在目录，边敲命令边传文件

### 端口转发（隧道）
- 图形化配置 SSH 隧道，把远程内网服务映射到本地端口访问
- 随时启停，状态一目了然

### 更多贴心细节
- 常用命令片段库，一键发送重复性命令
- 会话日志记录，操作留痕可回溯
- 断线自动提示，一键重连
- 单例应用：重复启动自动唤起已有窗口，不会越开越多

## 使用建议

1. 首次打开：在左侧新建一个会话，填写服务器信息保存
2. 双击会话即可连接；本机命令行走工具条的「本机终端」
3. 需要传文件？终端里点右键 →「SFTP 文件管理」

## 常见问题

- **连接提示缺少 ssh？** LYZTerm 使用 Windows 自带的 OpenSSH 客户端，请在
  「设置 → 应用 → 可选功能」中确认已安装「OpenSSH 客户端」
- **忘记密码？** 密码加密保存在本机，不上传任何服务器；重装并清理数据后需重新配置会话
